# ADR-0026: 챌린지 루틴 고정 정책 — 참여자 개인화 미허용

- **Status**: Accepted
- **Date**: 2026-05-21
- **Author**: Routinely Project

---

## 1. Context

챌린지에 참여한 사용자들은 동일한 루틴 템플릿(`owner_type = CHALLENGE`)을 공유한다.
이때 참여자가 `repeat_type`, `repeat_value`, `preferred_time` 등을 개인 선호에 맞게 수정할 수 있는지 여부를 결정해야 한다.

검토된 두 가지 방식:

**옵션 A) 개인화 허용**
- 참여자가 챌린지 루틴의 반복 유형·횟수를 자신의 수준에 맞게 조정 가능
- 예: 방장은 주 5회, 참여자 A는 주 3회로 설정

**옵션 B) 고정 (개인화 불가)**
- 챌린지 루틴 템플릿은 모든 참여자에게 동일하게 적용
- 예: "주 3회 러닝" 챌린지 → 전원 주 3회 기준으로 달성률 산출

---

## 2. Decision

**챌린지 루틴은 모든 참여자에게 고정으로 적용한다.**

- `routine_templates`의 `repeat_type`, `repeat_value`는 챌린지 생성 시 결정되며, 이후 참여자가 수정할 수 없다.
- 참여자별 `routines` 인스턴스는 동일한 템플릿을 참조하여 생성된다.

---

## 3. Rationale

### 3.1 리더보드 비교 공정성

달성률은 `accepted_count / total_scheduled`로 계산된다.
`total_scheduled`가 참여자마다 다르면 동일 기준의 비교가 불가능해져 랭킹 자체가 의미를 잃는다.

> A가 주 3회, B가 주 5회 챌린지를 선택했다면 이는 처음부터 다른 챌린지여야 한다.

### 3.2 챌린지 다양성으로 대체

다양한 강도 요구는 **챌린지 단위 다양성**으로 해결한다.

| 챌린지 | 루틴 | 대상 |
|---|---|---|
| "입문 러닝" | 주 2회 | 초보 |
| "중급 러닝" | 주 4회 | 중급 |
| "매일 러닝" | DAILY | 상급 |

사용자는 자신의 수준에 맞는 챌린지를 선택하면 된다.

### 3.3 개인 맞춤 루틴은 별도 분리

완전한 개인화가 필요한 경우 `challenge_id = NULL`인 **개인 루틴**(`owner_type = PERSONAL`)을 사용한다.
챌린지 루틴은 "공동 약속"의 성격이며, 개인 루틴은 "개인 목표"의 성격으로 명확히 분리된다.

---

## 4. Consequences

### 긍정적 영향

- 리더보드 달성률 비교가 공정하고 의미 있음
- 챌린지 루틴 관련 비즈니스 로직이 단순해짐
- `challenge_member_summary` 집계 로직 통일 가능

### 부정적 영향

- 참여자가 자신의 수준에 맞게 조정 불가 → 챌린지 설계 시 세분화 필요
- 향후 "챌린지 내 개인 목표 설정" 요구가 생기면 별도 설계 필요
